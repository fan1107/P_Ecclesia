# 에끌레시아 아트 적용 — 2026-11-04

## 화면 채우기
- PixelViewport가 상단 100 / 하단 150 UI 영역을 제외한 안전 영역 전체를 채움.
- 정수 배율 맞춤에 의한 테두리 여백 제거. 전체 지도를 잘라내지 않고 가로·세로를 표시 영역에 맞춤. Point 필터 유지.
- 터치 좌표도 동일한 표시 사각형으로 역변환. 화면 비율에 따라 가로·세로 확대 배율은 달라질 수 있음.

## 뜰 원근 제거 및 자유 이동
- CourtyardOrthographic.png: 돌길의 양쪽 선을 평행하게, 폭과 포장 돌 크기를 일정하게 수정.
- CourtyardLayout에서 양쪽 잔디를 이동 가능하게 열고 담장·벤치·게시판·큰 화단만 차단.
- Tools/ValidateCourtyard.ps1을 pwsh로 실행해 실제 경로 코드의 연결성을 검사. Unity Vector2Int만 테스트용 구현으로 대체.
- 이번 변경은 Unity MCP가 제공되지 않아 에디터 실행 검증은 미완료.

## 원본 시안 반영
- 원본을 참조해 교회 지붕·정원과 예배당 뒷벽·채광을 다시 맞춤.
- VisitorPortrait 스프라이트로 방문자를 교체. 기도 빛은 가장자리가 옅어지는 도트 효과로 표시.
- 세로 HUD 영역과 안전 영역을 제외한 공간에 배경을 정수 배율로 표시하여 하단 출입문이 가려지지 않도록 조정.

## 세로 화면 수정
- Android는 Portrait 고정. UI 기준 해상도는 720×1280.
- 승인 시안의 정원·화단·석재 길·목재 기둥·십자가를 보존한 CourtyardConcept / SanctuaryConcept 배경 사용.
- 기존 개별 소품 PNG는 보관만 하며 현재 화면은 세로 배경과 독립된 방문자/기도 효과로 구성.
- 이동 격자는 18×32. 장의자 좌표와 통로는 배경에 맞춰 조정.

## 이전 적용 이력
- 승인한 시안의 테라코타 지붕, 아이보리 벽, 올리브 녹색, 호박색 창문, 원목 장의자 색상을 적용.
- 교회 외관과 소품은 Resources/Art의 PNG를 사용. Furnishings는 좌상 나무, 우상 장의자, 좌하 강대상, 우하 창문의 2×2 아틀라스.
- 원근 수렴 없이 평행한 통로와 좌석을 배치. 중앙 십자가와 강대상이 보이도록 구성.
- 월드 카메라는 288×512 RenderTexture에 렌더링. Point 필터와 정수 배율 확대를 사용해 모든 배경을 같은 화면 픽셀 격자로 표시. UI는 별도 고해상도 Canvas.
- 남는 영역은 여백 처리하며, 터치는 표시된 월드 사각형 기준으로 역변환. 여백 터치는 무시.
- 원본 PNG는 Point, 무압축, 밉맵 없음으로 자동 임포트. 스프라이트는 알파 경계를 기준으로 분할하며 방 안에서 같은 소품을 재사용.

## 실행
Assets/Ecclesia/Scenes/Ecclesia.unity를 열고 Play → 오프라인 둘러보기.
교회 문을 누르면 입장. 장의자 좌석에 도착한 뒤 기도 시작.
에디터 Game View의 Ecclesia Portrait (720×1280) 설정으로 확인 가능.

## 검증 범위
Unity MCP로 실제 에디터에서 컴파일 및 Play 검증.
뜰 입장 경로, 예배당 20개 좌석/출구 경로, 좌석 도착과 기도 상태, 월드 중앙 및 여백 터치 좌표 확인.
화면 캡처는 Builds/ArtPreview에 저장.

이번 변경은 아트와 화면 표시 적용이다. Firebase 실제 계정 로그인, 다른 접속자 동기화, Android 실기기 검증은 별도 단계다.
기존 Builds/Android APK는 이전 그래픽 버전이며 이번 아트로 다시 빌드하지 않았다.
픽셀 워쉽 프로젝트는 수정하지 않았다.
